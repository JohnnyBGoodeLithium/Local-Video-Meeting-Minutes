## 实验进入与退出规则

- 使用虚构、公开或经批准且不进入 Git 的私有数据；公开记录只保留脱敏聚合结果。
- 未达到预设指标的实验不进入 CHANGELOG，也不写成已上线功能。

## 逐字稿修正后的纪要快速同步

- 日期：2026-08-31
- 问题：少量逐字稿修正后，完整重跑视觉和同步等待所有派生资产是否造成不必要等待？
- 假设：严格复用完整 VL 缓存、先发布 minutes/evidence、再低优先级更新脉络与检索，可显著缩短首个新纪要等待时间。
- 基线：标准重新生成纪要并同步完成所有派生阶段。
- 唯一变量：使用严格只读 VL 缓存并拆分首个可用结果。
- 数据集：虚构长会议和本地私有验证；私有内容不进入仓库。
- 指标：新纪要可读时间、完整同步时间、模型调用数、缓存缺失拒绝和 revision 正确性。
- 结果：能力已实现；真实耗时样本仍不足。
- 延迟与资源：待积累 3–5 次同类任务后比较。
- Token / API / GPU 成本：不重新运行视觉；文本纪要仍需要完整生成。
- 失败或退化：任一页面缺少有效视觉缓存时必须拒绝快速路径，不能生成伪完整结果。
- 结论：实现成立，收益幅度继续验证。
- 决策：采纳并继续验证。
- 若采纳，进入哪个版本：v0.15.1。

## 视觉疑难页二级路由

- 日期：待执行
- 问题：是否应让轻量 VL 处理普通页面，仅将复杂表格、图表、公式或冲突页交给更大模型？
- 假设：二级路由能以较低资源获得接近全量大模型的关键页面质量。
- 基线：全部页面使用当前主力 VL。
- 唯一变量：困难页判定和复核模型。
- 数据集：公开或虚构的普通幻灯片、密集表格、复杂图表、小字 OCR 与动态画面。
- 指标：页面事实准确率、纪要增益、升级率、总耗时与峰值内存。
- 结果：暂缓；当前用户对视觉增强的优先级低于会议回顾与 RAG 评测。
- 延迟与资源：未形成可比较数据。
- Token / API / GPU 成本：待测。
- 失败或退化：困难判定本身可能漏掉关键页；全量双跑会失去路由价值。
- 结论：保留候选方向，不进入当前计划。
- 决策：继续验证前暂停实施。
- 若采纳，进入哪个版本：未定。
