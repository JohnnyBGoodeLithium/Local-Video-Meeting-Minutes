## 等价云端 API 计算

当前本地模型没有“一模一样的按 token 托管 SKU”，所以使用同系列、相近能力的公开价格映射：

- 文本：Qwen3.6-35B-A3B，输入 ¥1.8/百万 token，输出 ¥10.8/百万 token。
- 视觉：Qwen3-VL-8B-Instruct，输入 ¥0.5/百万 token，输出 ¥2/百万 token。
- 可选 ASR：Paraformer 录音文件识别 ¥0.00008/秒。

价格来源均为阿里云百炼官方模型价格页：[文本与 VL token 价格](https://help.aliyun.com/zh/model-studio/model-pricing)、[Paraformer 秒计费](https://help.aliyun.com/zh/model-studio/model-pricing)。

计算拆分：

```text
文本输入：约 0.35–0.38M × ¥1.8/M       = ¥0.63–0.68
文本输出：约 0.044–0.054M × ¥10.8/M    = ¥0.48–0.58
VL 输入：  约 0.053M × ¥0.5/M          = ¥0.03
VL 输出：  0.042333M × ¥2/M             = ¥0.08
已有 VTT 合计                           ≈ ¥1.22–1.38
预留 tokenizer/格式修复偏差后            ≈ ¥1.25–1.45

无 VTT 时 ASR：7,347 秒 × ¥0.00008       = ¥0.59
无 VTT 合计                              ≈ ¥1.84–2.04
```

这个“无 VTT”方案假设声纹分离、跨会议身份匹配仍在本地。把声纹也送云会改变隐私边界，且不同供应商没有可直接对齐的统一单价。对象存储、上传流量、日志、企业网络与税费也未计入。

## 本地成本

本次各稳态阶段合计约 52.5 分钟：diarization 6.1 分钟、抽页 0.5 分钟、VL 24.6 分钟、纪要 14.4 分钟、Topic Map 7.0 分钟。失败重跑不是正常单场成本，应单独作为工程质量损耗统计。

```text
用电量 = 平均整机功率(kW) × 推理小时
电费   = 用电量 × 电价
折旧   = (硬件购置价 - 残值) ÷ 预计有效推理小时 × 本次推理小时
```

按 250–450 W、0.875 小时、HK$1.6/kWh 的纯计算假设，用电量约 0.22–0.39 kWh，电费 HK$0.35–0.63。这里的 HK$1.6 只是便于复算的假设，不是对当前电力公司的报价。若机器本来就用于日常工作，是否计整机折旧需要按实际财务口径决定。

## 如何解读

- 只看边际推理费，云端 token 很便宜，和钉钉 3,000 分钟套餐摊销已是同一数量级。
- 套餐买的是完整产品：录制入口、云同步、协作、模板、AI 问答和服务承诺，不能只拿 token 与订阅费做功能等价比较。
- 本地方案的经济优势会随月会议量增加，但更重要的价值是数据主权、可修改工程、Meeting Identity Core、逐结论 evidence 和可离线交付。
- 若以后允许用户选择云端，应把它设计成显式的 per-meeting policy：显示预估金额、将发送的模态、数据保留说明和本地 fallback，而不是静默切换。
