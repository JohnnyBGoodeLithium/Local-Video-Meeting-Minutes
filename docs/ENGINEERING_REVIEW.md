- 完成影响产品交互、数据格式、生成策略、隐私边界或运行架构的改动；
- 修复真实环境事故，或发现合成测试未覆盖的失效路径；

## 已处理

- 建立 Git 基线，并通过 `.gitignore` 隔离全部真实会议、录音、声纹、组织架构和运行状态。
- 分离代码根与数据根，测试/部署可独立指定私有数据位置。
- 将固定共享 `_smoke` 夹具改为每次独立临时根，消除多会话相互删除夹具的问题。
- 上传验证失败时清理半上传目录，并拒绝多音频、混合音视频和不明确的多 VTT 请求。
- 作业 JSON 不再保存任意 stderr，只保存受控元数据；dry-run 结果进入明确的 `result` 字段。
- 增加健康检查、环境 doctor、统一 Makefile 命令和依赖声明。
- 增加本地会议助手：结构化逐字稿引用、来源跳转、问答、纪要修改预览、revision 冲突保护、确认写入与历史备份。
- 将三栏工程控制台重构为会议回顾工作台：左侧播放/时间轴/逐字稿证据栏常驻，右侧阅读纪要，导入/作业/模型入口降级，底部自然语言助手常驻。
- 纪要修改改为可读的“保存/继续调整/取消”确认卡，并增加 revision 保护的一步撤销；自动回归覆盖应用与撤销闭环。
- 声纹库升级到 v3：稳定人员 ID、国际化类型名称和每人独立首选显示名；近似姓名只给候选，不再自动绑定。
- `/admin` 增加后台声音试听与候选 A/B 试听，并将 Org Chart 改为可增删、拖动改上级、服务端校验环路的图形画布。
- Org Chart 提取不再自动翻译、生成拼音、合并跨语言变体或创建虚假上级；草稿以增量方式进入人工确认流程。
- Org Chart 提取会在解析前剥离模型 thinking/analysis，并拒绝提示词回声行；逐页原始输出保存在私有数据根，便于本机排错但不进入作业日志。
- 回归覆盖近期遗漏的姓名新建、作业取消、上传清理、助手问答/修改、删除与数据根隔离。
- 纪要生成改为结构化 `meeting-minutes-prompt/v1`，用稳定 T/P/C ID 关联结论、逐字稿和页面；职级只作为决策权限语境，不直接决定结论权重。全部 VL 页面进入“有讨论/仅展示”附录（commit `829fa8d`）。
- 增加 `minutes.evidence.json`、版本化 RAG JSONL 和无需服务/LLM 的 `.meetingpack.zip` 静态查看器；Web 以轻量“依据”链接展示来源（commit `829fa8d`）。
