## 维护约定

本文是工程评审台账，不是一次性报告。出现以下情况时必须同步更新：

- 完成影响产品交互、数据格式、生成策略、隐私边界或运行架构的改动；
- 修复真实环境事故，或发现合成测试未覆盖的失效路径；
- 某一“仍需推进”事项完成、部分完成、取消或优先级改变；
- 开始新的大型能力之前，对依赖项、数据安全和回归范围进行复核。

更新时记录结果、对应 Git commit、验证方式和仍然存在的限制；完成项移入“已处理”，只有基础设施已具备但用户闭环尚未完成的事项标为“部分完成”。评审文档不得写入真实逐字稿、纪要正文、人员名单、凭据或私有原始路径。

- 人工验收集：单会议标注界面、`meeting-minutes-evaluation/v1` 本地事件格式、问题分类、汇总和失效规则已完成；尚未由用户完成首轮真实会议验收，也未实现跨会议、模型版本与 prompt 版本的对比汇总。
