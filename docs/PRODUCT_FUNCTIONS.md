## 维护规则

- 新增用户可感知功能时，必须在同一批提交中新增叶功能编号；不要等发布后补账。
- 重要增强沿用原编号，更新说明、版本和最近关键 Git 号；语义完全不同的新能力使用新编号。
- 删除功能不删除行，说明中标记“已停用”，保留最后上线版本与 Git 号。
- 未上线方案可以先占号，但上线版本号和 Git 号必须写“规划中”，不能预填预计提交。
- Bug 不使用本表编号；Bug 表字段和状态流由产品负责人另行确认后单独建立。
