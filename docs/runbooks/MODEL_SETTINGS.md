# 模型来源设置

在服务所在机器打开 **设置 → 模型**。文本/正式纪要与画面理解分别配置来源、API Base URL、模型 ID 和可选 API Key。视觉模型 ID 可留空以保留部署环境中的配置。模型文件仍由本地推理服务管理；填写文件下载地址不能代替启动推理服务。ASR、对齐和说话人模型继续使用既有本地配置。

本地来源只接受回环地址。云端来源支持 OpenAI 兼容的 Chat Completions 接口，必须填写 HTTPS 地址，并明确勾选允许发送对应任务内容；不自动回退到云端。不承诺支持厂商专有协议或所有云端模型的结构化输出参数。

“测试连接”只发送合成文本或测试图片，不发送会议资料，不保存测试回答。成功代表接口可响应，不代表长上下文、复杂图表或持续直播已经验证。正式纪要模型可以与通用文本模型不同，但应由同一文本端点提供。

配置保存在私有数据根 `config/model-providers.json`，文件权限为仅当前用户读写，不进入 MeetingPack。密钥不回显；留空只对相同端点保留已有密钥，切换地址不会把旧密钥发送到新地址。远程请求不跟随重定向。

保存配置不会切换正在运行的任务。待任务结束后，按原部署方式重启服务；页面显示是否仍有待生效设置。子进程继承服务启动时的配置快照。已有 `.env` 在没有设置文件时继续有效；设置文件中的模型字段优先。删除该设置文件并重启可恢复环境变量配置。

推荐链接是模型来源入口，不是自动下载、安装或质量保证：

- [Qwen3.6-35B-A3B GGUF](https://huggingface.co/ggml-org/Qwen3.6-35B-A3B-GGUF)：通用文本和画面理解候选；视觉服务需要匹配的 mmproj。
- [Qwen3.8-27B GGUF](https://huggingface.co/ggml-org/Qwen3.8-27B-GGUF)：正式纪要质量优先候选；按硬件验证速度、内存和上下文预算。

更改视觉来源后观察缓存身份随端点和模型变化；旧观察仍保留，但不会冒充新模型读取结果。切换前应保留当前已完成结果，按需重跑。
