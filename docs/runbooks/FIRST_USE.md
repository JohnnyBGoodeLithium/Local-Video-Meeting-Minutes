# 从部署到导出

这条路线帮助首次使用者完成一份可核对的结果。安装命令以[部署指南](DEPLOYMENT.md)为准；
仅打开页面不代表语音与模型已就绪。先用一段不含敏感资料的短录音验证，再处理长会议或发布会。

| 你要做什么 | 使用入口 | 完成标志 |
|---|---|---|
| 安装并运行处理服务 | Server / 本机工作台 | 检查通过，导入短录音后出现可播放逐字稿 |
| 在其他设备查看与轻量修正 | Companion | 完成私有网络配对，可看到服务端内容 |
| 把结果交给无需安装的读者 | 离线 Viewer | 解压 MeetingPack，直接打开 `viewer.html` |

## 1. 安装与检查

从 [GitHub Releases](https://github.com/JohnnyBGoodeLithium/Local-Video-Meeting-Minutes/releases)
下载应用包，或按部署指南获取源码。按自己的硬件配置依赖与本地模型，配置数据目录，启动服务。
说话人区分模型已随包提供，不需要额外的 HF 验证；语音识别、文本和视觉模型仍需部署者配置。
Linux/Bash 是当前完整部署说明的基线；Windows/macOS 浏览器可访问已部署的服务，
不代表这两种系统上的本地推理安装已经等价验证。离线 Viewer 不需要这些模型和服务。

成功标准：健康检查通过，浏览器可以打开工作台；导入短录音后可以播放、搜索并看到实际逐字稿。
模型报错时保留原文件，在任务详情中查看失败阶段，按[处理与恢复](PROCESSING_AND_RECOVERY.md)操作。

## 2. 导入你要处理的内容

- **会议**：导入录音或录屏；有 Teams 逐字稿时可一起拖入 VTT/DOCX。
- **媒体**：导入本地视频，或粘贴受支持的公开视频链接。先确认解析出的标题，再开始处理。
- **直播（实验）**：部署者启用后，从直播入口开始采集。采集期间可退出工作区，结束时选择“停止并整理”。

“快速纪要”先完成基于语音的纪要，之后可以补充画面；“完整分析”继续解读截图并整理多模态结果。
本地文件处理不需要上传云端；网络链接下载需要联网。

## 3. 等待时也能阅读

任务卡说明正在做什么以及队列位置；已有逐字稿可先阅读和回听。估时没有可靠依据时显示正在估算。
完成部分画面不代表每张截图都已解读。终稿未就绪、画面待核或翻译等待更新时，以页面状态为准。
队列上移、下移和下一项只改变等待顺序；安全切换只有在当前任务可恢复时可用。

## 4. 核对与修正

从议题或分析纪要开始，点击时间回到原声与画面。会议可按人物核听，视频可按主题和关键画面回顾。
未知说话人点“确认是谁”；转写错误修正逐字稿，术语或纪要修改先查看预览再保存。
画面中展示的方案不自动成为会议决定，模糊数字需要回到截图核实。正式修改保留恢复入口。

## 5. 在其他设备继续

Companion 需要服务端启用，并在受控私有网络中完成配对；手机、平板、笔记本可以发送内容、跟进任务与回顾。
它需要服务在线，不能替代离线包。真实手机与网络配置仍需在目标环境验证，部署参见
[Companion 部署指南](COMPANION_TAILSCALE.md)与部署者提供的配对页。
所有阅读端从页头“外观”设置明暗模式与高亮色；每台设备的浏览器各自保存设置。

## 6. 导出并验收

打开“导出”，按接收者选择：

- **离线 Viewer**：适合同事回顾。按需包含压缩音频或视频；解压后打开 `viewer.html`。
  不带媒体的包仍可阅读，但不能回听缺少的音视频。发送前检查标题、一个时间回跳、图片及语言切换。
- **AI / 知识库 Pack**：适合交给 AI 工具或知识库继续使用，保留来源关系。
  若把包上传外部 AI，内容会离开本机，应由使用者自行决定。

导出不会修改原会议；重复导出生成新的版本化包。处理未完成时先导出页面允许的核听快照，
不要把快照当作完整分析。旧包是当时的快照，后续修改需要重新导出。
