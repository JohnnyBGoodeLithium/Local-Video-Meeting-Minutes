# 全旅程 UX 走查记录

日期：2026-09-11。范围：部署文档、产品介绍、Server 工作台、人员设置、Companion 配对与阅读、离线 Viewer。
使用虚构资料和隔离数据目录，不通过视觉改版更改会议内容、人物身份或模型配置。

| 阶段 | 发现的问题 | 本轮处理 | 验证方式 |
|---|---|---|---|
| 了解产品 | Live 主介绍堆叠采集术语；UX 文档仍称无在线话题 | 用用户结果解释滚动文字、截图、回放与停止整理；兼容性折叠；更新实现边界 | 中英词典完整性、产品页浏览器旅程 |
| 首次部署 | 缺少从安装到产出的连续路线；不同使用端的安装要求易混淆 | 新增 FIRST_USE，明确 Server、Companion、Viewer 各自条件及短录音验收 | 文档链接校验；不宣称已重装各操作系统 |
| 导入与处理 | 完整分析与快速纪要、等待时可读内容容易误解 | 路线说明选择、状态与失败恢复；保持现有导入与队列行为 | 既有 API 与浏览器完整 smoke |
| 阅读与视觉 | 视频无标题图片沿用页码；旧系统默认标题继续流入 Viewer | 使用内容标题或“关键画面 · 时间”；会议幻灯片保留页码；兼容旧默认标题 | 视频与会议标题回归、离线 Viewer 启动 |
| 外观 | 三端默认主题和高亮色不一致，浅色存在固定深色底 | 共享语义颜色、字体与外观入口；支持系统/明/暗及四种高亮色 | 六页 × 明暗 × 桌面/手机截图；基本正文/辅助文字/高亮色对比度至少 4.5:1 |
| 小屏 | Viewer 页头挤出竖排标签，设置表格按钮断字 | 次要页头信息收起；表格局部滚动；操作文案不拆字 | 390px 及 1440px 浏览器布局校验与截图 |
| 设备连接 | 配对页中英文混用；撤销连接显示为 Allow；错误缺少反馈 | 中英完整操作、撤销就地确认、防重复提交、错误反馈；刷新不打断焦点或确认 | 合成配对 API 与浏览器链路；真实网络仍需目标设备验证 |
| 导出 | 离线包与在线外观割裂；接收者不知道需要哪些依赖 | Viewer 内嵌共享样式/脚本；首次使用说明解压、媒体选项与回跳验收 | 无服务、无外部资源的合成 Viewer；导出、回放/时间码、语言切换回归 |

动效仅用于操作反馈和弹层出现。系统减少动态效果优先；主题切换不会重新创建播放器。
外观偏好保存在浏览器，同源页面同步，不自动同步到另一台设备，也不写入会议或导出事实数据。

## 仍需目标环境验收

- 真机 iPhone/Android 的视频全屏、软键盘、设备休眠和网络恢复；桌面 Chromium 的移动视口不等于真机验证。
- Windows/macOS 本地推理安装不在本轮实测范围；这次统一浏览器体验不改变硬件部署支持边界。
- 复杂图表理解、长时直播和所有截图的质量筛选属于分析能力验证，不因 UI 改版变成已验证能力。

稳定交互合同见 [UX](../UX.md)，初次使用见 [FIRST_USE](FIRST_USE.md)。
