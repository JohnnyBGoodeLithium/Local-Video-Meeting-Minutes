# Release notes

This directory contains the delivery notes used as the body of future GitHub Releases.

- Start with the next formal Application Release; historical tags are not retroactively repackaged.
- Copy [TEMPLATE.md](TEMPLATE.md) to `vX.Y.Z.md`.
- Keep English first and Chinese second.
- Keep highlights user-facing and concise; use [CHANGELOG.md](../../CHANGELOG.md) as the repository version index and Git history for implementation detail.
- A release note filename must exactly match the tag that the Release workflow validates.
- While the major version is `0`, releases are published as pre-releases.

Creating this file does not authorize a tag or a GitHub Release. Both remain explicit maintainer actions.
