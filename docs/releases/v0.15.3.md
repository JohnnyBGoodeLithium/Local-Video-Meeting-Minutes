# v0.15.3

## English

### Highlights

- Fixed the official Application Release Bundle allowlist so the explicit release authorization marker is present during clean-directory verification.
- Added regression coverage that requires the authorization marker to be tracked, allowlisted, bundled, and equal to the release tag.
- Made Headless Chromium startup wait for a complete, parseable DevTools port file instead of treating file creation alone as readiness.

### Compatibility and migration

- Product UI, canonical meeting data, `job-progress/v2`, identity correction, model pipelines, and RAG behavior are unchanged.
- Use `v0.15.3` for the first downloadable Application Release Bundle. The immutable `v0.15.2` tag remains an auditable failed release attempt and has no GitHub Release assets.
- Distribution remains a source checkout or Application Release Bundle; there is no PyPI package, wheel installation contract, stable public Python API, or universal GPU/model lock.

### Known limitations

- This remains a controlled, local-first single-machine PoC rather than a production multi-user service.
- GPU, PyTorch, CUDA, ROCm, ASR, diarization, and model-service dependencies remain hardware-profile specific.
- The repository does not currently include an open-source license.
- Real model and hardware validation on the Lenovo host remains separate from synthetic hosted CI.

### Validation

- CI: frozen-lock verification and `make check` passed.
- Smoke: `make smoke` passed with 215 checks and required Headless Chromium journeys.
- Clean bundle verification: the complete allowlisted bundle was extracted into a new directory, installed from `requirements/ci.lock`, and passed `package-check` plus 215 smoke checks.

## 中文

### 主要变化

- 修正正式 Application Release Bundle 的 allowlist，使明确的发布授权标记能够进入全新目录验证。
- 增加回归门禁，要求授权标记必须被 Git 跟踪、纳入 allowlist、进入发布包，并与发布 tag 一致。
- Headless Chromium 启动改为等待完整且可解析的 DevTools 端口文件，不再仅以文件已经创建作为就绪条件。

### 兼容与迁移

- 产品 UI、canonical 会议数据、`job-progress/v2`、人物修正、模型管线和 RAG 行为均未改变。
- 首个可下载的 Application Release Bundle 请使用 `v0.15.3`；不可移动的 `v0.15.2` tag 保留为可审计的失败发布尝试，没有 GitHub Release 资产。
- 当前分发方式仍是 source checkout 或 Application Release Bundle；没有 PyPI package、wheel 安装合同、稳定 Python public API 或通用 GPU/模型锁。

### 已知限制

- 当前仍是本地优先的受控单机 PoC，不是正式多人生产服务。
- GPU、PyTorch、CUDA、ROCm、ASR、说话人和模型服务依赖仍按硬件 profile 管理。
- 仓库当前未附带开源许可证。
- Lenovo 本机的真实模型和硬件验证仍独立于使用虚构数据的 hosted CI。

### 验证

- CI：依赖锁漂移检查与 `make check` 通过。
- Smoke：`make smoke` 通过 215 项检查，并强制运行 Headless Chromium 旅程。
- 发布包全新目录验证：完整 allowlist 制品在新目录解包，从 `requirements/ci.lock` 安装，并通过 `package-check` 和 215 项 smoke。
