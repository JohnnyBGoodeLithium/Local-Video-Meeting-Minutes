# Local Video Meeting Minutes v0.16.4

## English

### Highlights

- Offline visual supplementation reads all missing retained frames by default, reusing valid observations. Explicit limits and checkpoint-only recovery remain available.
- Long topic maps and visual lists retain their reading position. Empty table/chart candidates are not treated as proven categories, and keyword mentions no longer imply core information.
- Local administrators can configure text, final-minutes and vision models, with Hugging Face source links and synthetic connection tests. Compatible cloud services require explicit opt-in; API keys stay private and are not echoed or forwarded through redirects.

### Compatibility and migration

Existing environment configuration remains supported. Saved model settings take effect after restarting the service; running jobs keep their original configuration snapshot. Cloud support targets OpenAI-compatible Chat Completions, not every vendor-specific protocol. Historical source-bound visual observations remain readable after prompt refinements; new inference uses current prompt provenance. Re-export MeetingPack for updated projections.

### Validation and limits

Release gates require full repository checks, isolated smoke, clean-bundle verification and hosted CI. Synthetic Chromium tests cover 300 frames, 60 topics, model settings, mobile layouts and offline reading. Cloud authentication and authorization use synthetic tests; no external account or private meeting content is used. Complex-chart accuracy still requires human verification.

## 中文

### 主要变化

- 离线画面补充默认读取全部未分析截图，复用有效观察；保留显式数量预算与检查点恢复。
- 长会议脉络和画面列表保留阅读位置；空表格/图表候选不直接当作已证实分类，关键词不再决定核心信息标签。
- 后台可配置文本、正式纪要和视觉模型，提供 Hugging Face 来源链接及合成连接测试。云端兼容服务需明确启用；密钥仅本机保存，不回显、不随跳转发送。

### 兼容与迁移

继续支持环境变量部署。保存模型设置后重启服务生效，运行中任务使用原配置快照。云端支持 OpenAI 兼容 Chat Completions，并非所有厂商专有协议。提示词修订后仍可阅读绑定原图的历史观察；新推理严格记录当前提示词来源。重新导出 MeetingPack 才会获得更新投影。

### 验证与边界

发布门禁要求完整检查、隔离 smoke、全新解压包验证及托管 CI。虚构 Chromium 旅程覆盖 300 张画面、60 个议题、模型设置、手机布局和离线阅读。云端认证和授权使用模拟测试，没有使用真实外部账户或私人会议内容。复杂图表正确性仍需人工核对。
