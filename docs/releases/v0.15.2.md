# v0.15.2

## English

### Highlights

- Added complete, structurally aligned English and Simplified Chinese repository entry points.
- Synchronized product metadata with `VERSION` and introduced reproducible Python 3.11 runtime and CI locks.
- Added an allowlist-built Application Release Bundle with ZIP and tar.gz assets, a file manifest, and SHA256 checksums.
- Added hosted validation for clean extraction, fresh dependency installation, package checks, Headless Chromium smoke, and tag-driven GitHub Releases.

### Compatibility and migration

- Existing application startup, canonical meeting data, `job-progress/v2`, identity correction, model pipelines, and RAG behavior are unchanged.
- Distribution remains a source checkout or Application Release Bundle. There is no PyPI package, wheel installation contract, stable public Python API, or universal GPU/model lock.
- Python 3.11 remains the supported baseline for the lightweight runtime and CI environment.

### Known limitations

- This remains a controlled, local-first single-machine PoC rather than a production multi-user service.
- GPU, PyTorch, CUDA, ROCm, ASR, diarization, and model-service dependencies remain hardware-profile specific.
- The repository does not currently include an open-source license.
- Real model and hardware validation on the Lenovo host remains separate from synthetic hosted CI.

### Validation

- CI: `make check` passed with frozen-lock verification.
- Smoke: `make smoke` passed with 215 checks and required Headless Chromium journeys.
- Clean bundle verification: 225 allowlisted files were extracted into a new directory, installed from `requirements/ci.lock`, and passed `package-check` plus 215 smoke checks.

## 中文

### 主要变化

- 建立结构一致、各自完整可读的英文与简体中文仓库入口。
- 将产品元数据与 `VERSION` 同步，并增加可复现的 Python 3.11 基础运行和 CI 依赖锁。
- 增加 allowlist 驱动的 Application Release Bundle，提供 ZIP、tar.gz、文件 manifest 和 SHA256 校验。
- 增加全新目录解包、重新安装、package-check、Headless Chromium smoke 和 tag 驱动 GitHub Release 的托管验证。

### 兼容与迁移

- 现有应用启动方式、canonical 会议数据、`job-progress/v2`、人物修正、模型管线和 RAG 行为均未改变。
- 当前分发方式仍是 source checkout 或 Application Release Bundle；没有 PyPI package、wheel 安装合同、稳定 Python public API 或通用 GPU/模型锁。
- 轻量运行环境和 CI 继续以 Python 3.11 为基线。

### 已知限制

- 当前仍是本地优先的受控单机 PoC，不是正式多人生产服务。
- GPU、PyTorch、CUDA、ROCm、ASR、说话人和模型服务依赖仍按硬件 profile 管理。
- 仓库当前未附带开源许可证。
- Lenovo 本机的真实模型和硬件验证仍独立于使用虚构数据的 hosted CI。

### 验证

- CI：`make check` 与依赖锁漂移检查通过。
- Smoke：`make smoke` 通过 215 项检查，并强制运行 Headless Chromium 旅程。
- 发布包全新目录验证：225 个 allowlist 文件在新目录解包，从 `requirements/ci.lock` 安装，并通过 `package-check` 和 215 项 smoke。
