# Local Video Meeting Minutes v0.16.2

## English

### Highlights

- Visual progress counts the current analysis pass, rather than all retained screenshots. Estimates identify when they cover only the current stage.
- Failed generation resumes a completed visual pass or retries its missing pages without expanding the backlog. Existing transcripts remain readable.
- Synthesis prompts remove display geometry and duplicate metadata while retaining readings, units, qualifiers and unresolved conflicts. Original observations remain intact.
- Minutes can use an explicit context capacity for each model alias, with output and safety reserves. Truncated notes receive one bounded retry from original evidence.
- Audio/visual comparison explanations and citations are bounded to prevent lengthy reasoning from exhausting output budgets.

### Compatibility and migration

This is a patch release; no meeting schema migration is required. It includes the structured local visual workflow and bundled diarization introduced in the v0.16.1 source tag. Configure context capacities to match the actual capacity of each inference slot, not the server total. See [visual processing](https://github.com/JohnnyBGoodeLithium/Local-Video-Meeting-Minutes/blob/v0.16.2/docs/runbooks/VISUAL_PROCESSING.md).

### Known limitations

Retaining screenshots does not mean every screenshot has been analyzed. Partial reads and conflicting observations still require review. Semantic image-quality ranking and universal chart accuracy are not claimed. A larger context window does not by itself improve factual accuracy or remove long-input processing costs.

### Validation

Required release gates: `make check`, `make smoke`, `make release-verify`, and the hosted Release workflow. Synthetic regressions cover progress, context budgets, source-preserving prompt projection and bounded recovery. Local slot allocation and basic inference were checked; full-window load and representative content quality require separate evaluation.

## 中文

### 主要变化

- 视觉进度按本轮实际请求统计，不再把全部保留截图作为分母；只估算当前阶段时明确标注。
- 失败恢复复用已完成的视觉轮次或只补原计划缺页，不自动扩展下一批图片；已有逐字稿保持可读。
- 纪要提示词移除显示坐标和重复元数据，保留读数、单位、限定条件与未解决冲突，原始观察不变。
- 可按模型别名配置单请求上下文容量，并预留输出及安全空间；笔记截断时只从原始证据有界重试一次。
- 限制语音/画面互校的解释长度和引用数量，避免冗长推理耗尽输出预算。

### 兼容与迁移

这是补丁版本，无需迁移会议 schema；包含 v0.16.1 源码标签中的结构化本地视觉流程及内置说话人模型。上下文容量应匹配推理服务的实际单槽容量，不能使用多槽总容量。详见[视觉处理](https://github.com/JohnnyBGoodeLithium/Local-Video-Meeting-Minutes/blob/v0.16.2/docs/runbooks/VISUAL_PROCESSING.md)。

### 已知限制

截图全部保留不等于全部完成理解；部分读取和来源冲突仍需复核。本版不宣称已实现语义图片质量排名或通用图表完整解读。扩大上下文不会自动提高事实准确率，也不会消除长输入的处理耗时。

### 验证

发布须通过 `make check`、`make smoke`、`make release-verify` 和托管 Release 工作流。合成回归覆盖进度、模型预算、保留来源的提示词投影和有界恢复。本地已检查槽位分配与基本请求；满窗口负载和代表性内容质量仍需单独评估。
