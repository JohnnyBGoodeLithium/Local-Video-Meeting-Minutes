# meeting-minutes Web 界面

本机 Web 应用（FastAPI + 原生前端，无构建步骤，不引用任何 CDN）。
**只监听 127.0.0.1:8899，内容不出本机。**

## 启动

```bash
cd ~/meeting-minutes
.venv/bin/python web/server.py
# 浏览器打开 http://127.0.0.1:8899/       会议回顾工作台
# 浏览器打开 http://127.0.0.1:8899/admin  人员身份 + 声纹试听/确认 + 图形化 org chart
```

## 功能

- 左栏“导入会议”可选择或拖入视频（可带同名 .vtt）或音频 → 自动路由：
  视频+vtt → `bin/teams_minutes.py`；裸视频 → `bin/video_minutes.py`；音频 → `bin/run_all.py`。
  上传存 `recordings/inbox/<jobid>/`，作业状态在 `web/jobs/<id>.json`（只存元数据行）。
  管线启动后会把媒体以 CoW reflink（不支持时复制）固化为独立会议母版，会议不再依赖 inbox 路径；处理成功后自动清理上传暂存。旧会议缺少本地 `audio.wav`
  时，播放接口会回退到 `source.json` 中仍有效的音频路径。
  有活动作业时，左栏自动出现“正在处理”面板（4s 轮询）；等待项显示实际队列序号并有**优先**按钮
  （`POST /api/jobs/{id}/prioritize`：只排到当前运行任务之后，不抢占）。默认优先级为会议处理 > 纪要/脉络 > 翻译。
  排队/运行中的作业另有**取消按钮**（`POST /api/jobs/{id}/cancel`：排队直接移除；运行中整进程组 SIGTERM，5s 不死再 SIGKILL）。
- 详情页：左侧常驻播放器、双层时间轴和逐字稿证据栏，右侧可切换“会议纪要 / 章节脉络 / 屏幕内容 / 结论审计”。时间线上层是 AI 归并的整场论点，同一论点可跨多个时间区间；下层是页面每次实际出现的区间。章节页用“整场会议—一级论点—背景/观点/约束/决定/行动/风险/待确认”思维导图展示，不以截图作为节点；屏幕页以缩略图和标题浏览 VL 资料。时间轴论点点击会播放并定位右侧，右侧节点点击只查看，显式播放按钮才跳转。页面判定默认忽略右侧参会人栏、抑制稀疏红框/激光点并强化顶部大标题；保存的截图仍是完整画面。
  重新生成、全文优化、离线查看包导出与高级配置收在“更多”中。查看包默认不带音视频，解压后双击
  `viewer.html` 即可离线阅读、搜索和核对纪要依据。包顶层只保留 Viewer、README 和 assets；也可选择 AAC 分享音频或 720p 分享视频，原始母版不被修改。“存储与清理”按母版、阅读资产、可再生缓存显示占用，并只清理白名单缓存。
- 带录屏会议渐进发布：转写与说话人完成后自动打开语音草稿，可播放、翻译和追问；VL 后替换为多模态终稿。草稿阶段暂停编辑、结论审计、会议脉络与导出，界面和 API 均执行这一版本边界。
- 顶栏中文/EN 会同步切换界面、纪要与会议脉络。Topic Map 译文由 `/translations/topic-map` 按需生成，结构关系和证据 ID 始终复用 canonical 数据。
- 右侧“结论审计”把结构化结论变成逐条核对卡：可标记结论与依据一致、把提议写成决定、遗漏/弱化决定、引用依据错误、
  负责人/期限错误、缺少原文支持或暂时无法审计。默认只显示待审计条目，支持数字键 1–7 快速判断；
  “核对依据”会定位左侧逐字稿/播放时间。结果追加写入私有数据根的 `evaluations/`，不改正式纪要，
  也不复制 claim 正文；相关逐字稿、身份或页面依据变化后，旧判断自动标为过期。
- 底部会议助手：直接输入问题或修改指令，也可逐轮点击或跨轮选择文字作为引用；本地 Qwen3.6 问答带时间来源。
  修改纪要先显示目标、说明和修改后预览；保存后在 `.history/minutes/` 留档，并可在没有后续改动时立即撤销。
- 逐字稿支持“原文 / 译文 / 对照”三种显示，并独立选择译为中文或 English。纯中文会议默认推荐英语，
  纯英文会议默认推荐中文；后台按目标语言分别生成 `transcript.translation.zh-CN.json` 或
  `transcript.translation.en.json`。翻译使用相邻发言、已确认名称、页面和关联结论消歧，但结论被明确视为
  低信任背景，不能向原话补事实。已经是目标语言的原话不重复显示，其他语言/混合轮次可随时展开原文；依据跳转会自动把
  关联轮次及相邻上下文展开为对照并插入优先队列。完整轮次按批次渐进显示，顶部展示进度条和完成数；
  可停止、继续或从失败批次续跑，当前播放位置也会优先。译文独立缓存，不覆盖逐字稿，逐字稿或身份变化后自动失效。
- 顶栏“中文 / EN”切换在线界面与会议纪要。纪要译文按 Markdown 块后台生成，保留 evidence marker，分别写入
  `minutes.translation.zh-CN.json` / `minutes.translation.en.json`；它们绑定当前纪要与证据语境 revision，不覆盖 `minutes.md`。
  全局阅读语言不强制改变逐字稿模式，逐字稿仍由上面的原文/译文/对照控件独立控制。
- 说话人 chip → 绑定弹框（可试听该声音片段）→ 一次绑定该声纹在本会议的全部语句
  （同时改写 transcript.spk.json / transcript.spk.md；纪要需手动点"重新生成"）。
  **名字不要求预先存在**：唯一精确已确认名称可直接绑定；相似名称只返回候选，不写库；用户也可显式“新建人员”。
- `/admin` 人员身份：同一稳定人员 ID 可保存 Org Chart 原名、中文名、全拼、英文名加姓氏等类型化名称，并独立设置首选显示名。
- `/admin` 声音确认：列表内试听、确认弹窗试听及候选人 A/B 试听；支持绑定、新建、解绑和声纹合并。
- `/admin` Org Chart：纵向可折叠层级画布（大组织默认折叠到一级、多个根自动换列）、选中节点就地快捷操作、无确认弹窗的拖动改上级、根节点放置区、未入图人员托盘、撤销和服务端环路校验；拖动只改本地草稿，点击保存后才写入。参考文件上传后可提取为增量草稿（PDF 用 pdftoppm 渲成页图）。

## 环境变量（测试用）

- `MEETING_WEB_BANK`：声纹库目录（默认 `speaker_bank/`）。测试时指向临时假库，不碰真实 bank.json。
- `MEETING_DATA_ROOT`：私有数据根（默认项目根）；测试时指向一次性目录。
- `MEETING_WEB_JOBS`：作业 JSON 目录（默认 `web/jobs/`）。
- `MEETING_WEB_PORT`：端口（默认 8899；与其他实例冲突时可改，如测试用 8898）。
- `MEETING_WEB_DRYRUN=1`：作业干跑——管线只执行 `<脚本> --help` 校验调用链，regen 直接标记完成。
- `MEETING_LLM_API` / `MEETING_LLM_MODEL`：助手使用的本机 OpenAI-compatible API 与模型。

`MEETING_MINUTES_ROOT` 仅作为旧版兼容变量保留。

## 测试夹具

合成夹具包含 10 秒静音、虚构 Alice/Bob 对话、2 页假 slides 和假 minutes.md。
`web/tests/run_smoke.py` 每次在独立 `tempfile` 根目录中生成并销毁它；不得把测试服务指向真实数据根。
当前回归同时覆盖结论审计保存、指纹冲突、相关内容变化后的失效和会议删除清理。
