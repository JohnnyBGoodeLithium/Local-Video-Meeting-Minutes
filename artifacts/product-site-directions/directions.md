# Product Site Art Direction Study

本轮只探索 Hero 与 Verify，不是正式实现。`web/static/product.html`、`product.css`、产品版本和 Web build 均未修改。

## 唯一任务、读者与视觉材料

- 唯一任务：让需要复盘会议或产品视频的知识工作者在三秒内明白——会议按人物进入，视频按议题进入；找到片段后，重要结论可以回到原声、时间码和当时画面。
- 目标读者：需要从长会议、发布会、产品讲解中准备汇报、核对决定或复用可信上下文的产品、工程、研究与管理人员。
- 产品材料：人物、议题、时间线、相关片段、重要结论、原始声音、时间码、当时画面和核对后的上下文流向。
- 共同约束：只使用 Northstar 虚构数据；第一轮只使用系统字体；中文与英文使用不同字距、行高和换行；不使用浏览器三圆点、玻璃、渐变光球、三列 feature cards 或左文右 Dashboard。

## A · 证据剪接 / Evidence Splice

把时间线当作整页构图网格。用户不是在“阅读功能”，而是在一根证据针上看人物、相关片段、结论和来源如何对齐。

### Palette

- Cutting Mat `#E7ECE9`：冷灰绿工作面
- Frame White `#FBFCFA`：核证区域
- Carbon `#15201D`：正文与轨道基准
- Person Teal `#167467`：人物与人物片段
- Track Grey `#AAB7B1`：未聚焦时间线
- Evidence Red `#C94F2D`：证据针、时间码与核证动作

### Typography

- 中文展示：`PingFang SC / Microsoft YaHei / Noto Sans CJK SC`，中等偏重，字距 `-0.025em`，行高 `1.12`。
- 英文展示：`Segoe UI` 系统无衬线，较窄行宽，字距 `-0.035em`，行高 `1.03`。
- 正文：同一系统无衬线；中文 `16–17px / 1.72`，英文 `17px / 1.62`。
- 时间码：`SFMono / Cascadia Mono / Consolas`，等宽数字。

### Layout

- 桌面：论点在上，完整宽度的剪接轨道在下；人物和议题是轨道的两个入口，结论和当时画面分居证据针两侧。
- 移动：轨道转为纵向阅读，证据针贯穿人物、议题、结论与画面；不隐藏未选入口。

### Signature

Evidence Needle：唯一的红色证据针贯穿时间线并落到时间码。它表示“这条结论在这里回到来源”，不是装饰线。

### Restraint

禁止蓝色主按钮、浏览器外壳、卡片阵列、圆角系统、装饰序号、浮动光影和与时间无关的线条。

## B · 核证折页 / Source Fold

把核证过程视为一张可折开的来源案卷。核心不是“文档感”，而是来源括号如何把结论、原话与画面归为同一组证据。

### Palette

- Document Field `#F4F7FB`：冷白蓝页面底
- Sheet `#FFFFFF`：案卷正文
- Archive Ink `#18263A`：标题与正文
- Margin Blue `#C9D4E2`：结构边界
- Source Wine `#A3384A`：来源括号与核证动作
- Confirmed Green `#32705A`：人物确认和已选状态

### Typography

- 中文展示：系统宋体优先（`Songti SC / STSong / Noto Serif CJK SC / SimSun`），正常字宽和 `0.015em` 字距，行高 `1.2`。
- 英文展示：`Georgia`，紧凑字距 `-0.035em`，行高 `1.07`。
- 正文：系统无衬线；中文 `16px / 1.75`，英文 `16–17px / 1.65`。
- 时间码：系统等宽字体，不使用印章式全大写。

### Layout

- 桌面：标题先完整结束，说明在下一栅格行向右错位承接，避免进入标题的纵向区域；案卷紧随其后占据主体宽度并从右侧轻微偏移。人物/议题在页边，结论和画面在折页正文中。
- 移动：折页接近满宽展开为单列，来源括号留在左侧，维持分组关系，并减少标题与案卷之间的空场。

### Signature

Source Bracket：酒红色来源括号把选中入口、结论、原话和画面括成一组，像审阅时的边注，但只表达真实证据关系。

### Restraint

禁止米白怀旧纸张、密集报纸分栏、假印章、文件夹拟物、堆叠阴影、三列 feature cards 和“合规 SaaS”图标库。

## C · 声画同帧 / Sound / Frame Cue

把产品最独特的能力压缩为一条同步字幕带：原声波形在上，当时画面在下，结论与时间码必须共享同一条带。

### Palette

- Stage Indigo `#292747`：声画观看环境
- Subtitle Ivory `#F5F0E6`：字幕带与关键结论
- Wave Mint `#75B9A7`：人物声音与相关片段
- Cue Coral `#F07355`：播放位置、证据时间码
- Frame Violet `#48446E`：画面与入口表面
- Muted Lavender `#BDB7D4`：辅助文字

### Typography

- 中文展示：系统无衬线中等字重，字距 `-0.015em`，行高 `1.16`；避免电影海报式超粗字。
- 英文展示：`Segoe UI`，字距 `-0.035em`，行高 `1.02`，控制在 2–4 行。
- 正文：系统无衬线；中文 `16–17px / 1.72`，英文 `17px / 1.62`。
- 时间码：系统等宽字体，与 Cue Coral 绑定。

### Layout

- 桌面：标题居中，人物/议题、波形和画面组成全宽声画台；结论以横贯视口的浅色字幕带出现。
- 移动：标题左对齐，字幕带出血到页面边缘；波形、原话、画面按播放顺序纵向排列。

### Signature

Synchronized Subtitle Band：全站唯一的浅色字幕带同时携带结论、人物和 `42:18`，上接原声、下接画面。

### Restraint

禁止近黑加荧光色、玻璃面板、霓虹、电影胶片孔装饰、渐变、播放平台仿制、巨型数字和无意义波形背景。

## 自我批评

以下判断来自 GitHub CI 的真实 Chromium 截图，而不是静态源码预览。三组均验证了中文、英文、1440px 和 390px；初次截图暴露 runner 缺少 CJK 字体，补齐 Noto Sans / Serif CJK 后才进入本轮评审。

### A · 证据剪接

- 任意 AI SaaS 风险：低。拿掉人物、议题、时间线和证据针后构图就失去主体，不是只换文案仍成立的通用 Hero；但标题区本身仍是常见的主标题加说明。
- 左文右卡风险：低。桌面首屏上方仍有左右文本关系，但核心仪器横贯全宽，不是右侧 Dashboard；移动端按证据顺序展开。
- 中文排版：无衬线字重和紧字距自然，桌面标题两行、移动标题两行；正文行长合适。移动端证据针穿过部分结论和原话，表达关系的同时也会干扰阅读。
- 三秒理解：三者中最快。人物入口、议题入口、时间线、结论与 `42:18` 在一个视域内。
- Signature 来源：强。Evidence Needle 直接表达“结论在此回到来源”，不是装饰。
- 主要修正点：若被选中，应让移动证据针停在内容边缘或段落之间，不能穿过文字和按钮。

### B · 核证折页

- 任意 AI SaaS 风险：最低。案卷、来源括号、人物、原话与画面形成一套核证语言；换成普通生成式 AI 文案会显得不成立。
- 左文右卡风险：低。Hero 是偏移案卷，Verify 是暗场中的完整来源组；不是固定左右分栏。桌面留白较多，但留白围绕案卷展开，而非展示空洞的品牌姿态。
- 中文排版：Noto Serif CJK 的标题和结论比通用无衬线更有审阅感，字距与换行自然；正文保持无衬线。移动案卷略窄，较长结论容易产生过多断行。
- 三秒理解：中等偏快。人物／议题和时间线清楚，但来源括号的含义需要比证据针多半拍理解。
- Signature 来源：强。Source Bracket 把结论、原话和画面定义为同一来源组，源于产品核对流程。
- 主要修正点：若被选中，应增宽移动案卷的有效文本区，并避免把“案卷感”做成怀旧文档拟物。

### C · 声画同帧

- 任意 AI SaaS 风险：中等。字幕带、波形和时间码来自产品，但深色舞台也可能被误读为视频编辑或生成式媒体产品。
- 左文右卡风险：低。桌面与移动都以全宽声画台和字幕带组织，不存在右侧 Dashboard。
- 中文排版：字重、字距和两行标题自然；深色背景上的辅助文字对比更克制，但小字号信息密度比 A / B 高。
- 三秒理解：快。人物、议题、时间线、横贯结论和当时画面连续出现；“返回原声”比“核对来源”更先被感知。
- Signature 来源：强。Synchronized Subtitle Band 同时承载结论和 `42:18`，上下连接原声与画面。
- 主要修正点：若被选中，应降低暗色块密度，让真实波形更早进入 Hero，并持续避免靠霓虹或播放平台拟物增强气氛。

## 建议

优先选择 **B · 核证折页** 作为正式方向。它最难被换一份文案变成任意 AI SaaS，中文与英文各自有明确的展示字体策略，且 Source Bracket 来自产品的核证关系。A 是三秒理解最强的保守选择；C 的声画叙事成立，但通用媒体产品联想最重。
